## The line

> The homework saw me eat the chicken off the counter, so I ate the homework too. A dog leaves no witnesses.

One line, 106 characters. The field is drowning in grading dogs, "show your working" literalists, floor-law lawyers and stomach archivists — this one is the angle nobody wrote: the homework is a witness to the dog's chicken theft, and a dog leaves no witnesses.

## How it runs

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — UTF-8, no trailing newline — and leaves the file readable by every user (0644, folders 0755).

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
